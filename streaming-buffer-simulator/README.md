# 串流播放與緩衝模擬器

互動式展示串流播放器如何讀取 HLS manifest、下載 segment，以及在網路速度低於播放速度時耗盡 buffer 並進入重新緩衝。

## 使用方式

直接開啟 `index.html`，或在此目錄啟動任何靜態檔案伺服器。

- **播放／暫停**：開始或凍結模擬（包含下載）。
- **重新開始**：清空播放與緩衝狀態，保留設定的網路速度。
- **網路下載速度**：藍色邊框區可手動拖曳滑桿，或使用方向鍵調整。範圍為每秒 0–5 個片段，0 代表斷線。
- **即時顯示**：緩衝量與片段進度僅供觀察，不可直接修改。

播放流程依序為 `Buffering → Reading Manifest → Buffering → Playing`。播放器會先累積 2 個 segment 才開始播放，並將預載上限維持在 5 個 segment；耗盡後也會重新累積到 2 個才繼續。

播放線以每秒 1.6 個片段前進。下載速度低於播放速率時轉為橘色，否則為藍色。若剩餘內容已全部下載，無須等待 2 個片段即可繼續播放至結束。播放清單讀取使用固定延遲，工具不會傳輸實際影片。

工具不需要套件、建置流程或後端服務。
